Backup sem perder a versão mais nova

Escolha uma pasta de origem e uma de destino. O programa copia tudo, incluindo as subpastas, e quando o arquivo já existe no destino ele só substitui se o da origem for de versão ou data mais recente.

Baixar Backup.exe Ver o código

Windows 10/11 · não precisa instalar · cerca de 10 MB

Como ele decide

  1. O arquivo não existe no destino

    É copiado.

  2. O conteúdo é idêntico

    Não faz nada, mesmo que a data seja diferente. A comparação é byte a byte.

  3. Os dois têm número de versão

    Programas e bibliotecas (.exe, .dll...) trazem a versão gravada no arquivo. Se forem diferentes, só substitui quando a versão da origem for maior, seja qual for a data.

  4. Nos demais arquivos

    Compara a data de modificação e só substitui quando a da origem for mais recente.

O que aparece no log

AçãoQuando
COPIADOArquivo novo, que ainda não existia no destino
SUBSTITUIDOA origem tinha versão maior ou data mais recente
IGNORADOIdêntico, ou o destino já estava igual ou mais atualizado

Como usar

  1. Abra o Backup.exe.
  2. Em Origem, escolha a pasta que você quer guardar.
  3. Em Destino, escolha onde vai a cópia (um HD externo, pendrive, outra pasta).
  4. Se quiser ver antes o que vai acontecer, marque Simular: nada é gravado.
  5. Clique em Iniciar backup. Dá para cancelar no meio.

Detalhes que evitam surpresa

Rodar de novo é rápido

A cópia mantém a data original do arquivo, então na próxima vez só vai o que mudou.

Pendrive e HD externo

Diferença de até 2 segundos na data conta como igual. Discos FAT/exFAT gravam a hora com essa precisão.

Sem cópia dentro de si mesma

O destino não pode estar dentro da origem, nem o contrário, para não entrar em laço.

Nunca apaga nada

Arquivos que só existem no destino ficam onde estão. O programa só copia e substitui.

Para quem quer mexer no código

A regra de decisão fica em backup.py, separada da janela (app.py, em Tkinter), e é coberta por testes unitários. A versão dos executáveis é lida pela API de versão do próprio Windows.

python app.py                              rem roda sem compilar
python -m unittest discover -s tests -v    rem testes
build.bat                                  rem testa e gera o Backup.exe
